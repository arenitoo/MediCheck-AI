# MediCheck-AI
App de Triagem Médica Baseada em IA
Tecnologia: O aplicativo será desenvolvido em Flutter para multiplataforma (iOS e Android), utilizando integrações com APIs de Machine Learning para processar os sintomas e gerar as recomendações.
Instalação e Configuração

## Clone o Repositório:

git clone https://github.com/arenitoo/MediCheck-AI.git

## Instale as Dependências:

### Backend:

cd backend

`npm install`

### Frontend:

cd frontend

`flutter pub get`

Configuração do Firebase:

Adicione os arquivos de configuração do Firebase ao projeto Flutter e backend.

Execute os Serviços:

Inicie o backend:

`npm start`

Inicie o frontend:

`flutter run`
